## Requirement

The current app has grown past what a top-nav + dense header can carry
cleanly. New surfaces — profile MFA, admin MFA, upcoming admin oracle
mappings, upcoming compliance sub-tabs — need a home that scales
without more chrome.

Users want:
- **Collapsible groups** in a left sidebar: click a group to expand,
  children appear underneath.
- **Collapsible sidebar itself** (full / icons-only / hidden), per
  user, remembered across sessions.
- **Config-driven**: adding a page = one entry in a config array,
  not a layout change.
- **Persona-aware**: entries declare required roles; the sidebar
  shows only what the caller can use.

Scope confirmed with user: **full re-shell** (sidebar replaces
PersonaNav AND the dense header shrinks to breadcrumb + action menu).
Config scope: **user-only** (localStorage, no backend change).
